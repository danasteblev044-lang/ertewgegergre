# 🤖 Селеста (Selesta) — Персональный ИИ-Агент в Telegram для Eskalane Helper

Интеллектуальный Telegram-бот **Селеста** с долговременной памятью, доступом в интернет, анализом любых документов/фотографий, автоматическим расписанием для группы **П1-25В** (с поддержкой числителя и знаменателя) и мониторингом жалоб на администрацию **Majestic RP Memphis**.

---

## 🌟 Ключевые возможности

1. **🧠 Постоянная память и профиль:**
   - Помнит, кто вы (**Eskalane Helper**, администратор на **Majestic RP Memphis**, студент колледжа СОТА группы **П1-25В**).
   - Ведет краткосрочную память диалога (контекст беседы).
   - Обладает долговременной памятью фактов (SQLite база `bot_data.db`) — запоминает любые привычки, предпочтения и факты, которые вы ему говорите.

2. **📅 Умное расписание группы П1-25В:**
   - В бота зашито официальное расписание на 1 семестр 2026–2027 учебного года.
   - Автоматически рассчитывает **числитель** и **знаменатель** относительно опорной недели (текущая неделя с 12.10.2026 — числитель).
   - Отвечает на естественные запросы: *«Какое расписание на завтра?»*, *«Что сегодня?»*, *«Какие пары в четверг?»*, *«Какая сейчас неделя?»* и др.
   - В четверг на 3-й паре автоматически выбирает предмет:
     - **По числителю:** *ОГСЭ.02 История (Воробьева К.А., каб. 211)*
     - **По знаменателю:** *ОП.03 Информационные технологии (Крупенева А.М., каб. 404)*.

3. **🛡️ Мониторинг жалоб на Majestic RP Memphis:**
   - Отслеживает раздел [«Жалобы на администрацию»](https://forum.majestic-rp.ru/forums/zhaloby-na-administratsiyu.1519/).
   - Ищет темы с упоминанием ника `Eskalane Helper` / `Eskalane`.
   - **Игнорирует уже рассмотренные/закрытые жалобы** (фильтрует по префиксам «Рассмотрено», «Закрыто», «Отклонено», «Одобрено» и т.д.).
   - **Не повторяется:** сохраняет просмотренные ID тем в базу данных.
   - **Режимы проверки:**
     1. **При каждом вашем запросе** к боту проверяет актуальные жалобы.
     2. **Раз в 2 часа**, если вы не общались с ботом, фоновый процесс сам проверит форум и пришлет тревожное уведомление с ссылкой на жалобу.

4. **📁 Чтение любых файлов, документов и фотографий:**
   - **Фото / Скриншоты:** использует мультимодальное компьютерное зрение LLM (Vision).
   - **PDF-файлы:** извлекает текст по страницам.
   - **Word (DOCX):** встроенный XML-парсер текста без лишних библиотек.
   - **Текст / Код / Таблицы:** `.txt`, `.py`, `.json`, `.csv`, `.md`, `.log` и др.

5. **🌐 Полноценный выход в интернет:**
   - Функция веб-поиска (DuckDuckGo) для получения свежих новостей, гайдов, информации по играм и коду.

6. **⚡ PlusVibe API:**
   - Работает через `https://plusvibeapi.ru/v1` (OpenAI-совместимый протокол).
   - Поддерживает любые современные модели: `gpt-4o`, `gpt-4o-mini`, `gemini-1.5-pro`, `claude-3-5-sonnet` и др.

## 🚀 Быстрый запуск

### 1. Установка зависимостей

Убедитесь, что у вас установлен Python 3.10 или выше:

```bash
pip install -r requirements.txt
```

### 2. Настройка файла конфигурации `.env`

Создайте файл `.env` на основе примера `.env.example`:

```bash
cp .env.example .env
```

Откройте `.env` и укажите свои данные:

```env
# 1. Токен бота от @BotFather в Telegram
TELEGRAM_BOT_TOKEN=123456789:ABCdefGHIjklMNOpqrSTUvwxyz

# 2. Ваш API ключ от PlusVibe (https://plusvibeapi.ru/v1)
PLUSVIBE_API_KEY=ваш_ключ_plusvibe

# 3. Базовый URL API
PLUSVIBE_BASE_URL=https://plusvibeapi.ru/v1

# 4. Модель (gpt-4o, gpt-4o-mini и т.д.)
AI_MODEL=gpt-4o

# 5. Ваш Telegram ID (узнать у бота @userinfobot), чтобы получать фоновые алерты
TELEGRAM_ADMIN_ID=123456789

# 6. Никнейм на Majestic RP
MAJESTIC_NICKNAME=Eskalane Helper
MAJESTIC_FORUM_URL=https://forum.majestic-rp.ru/forums/zhaloby-na-administratsiyu.1519/
```

### 3. Запуск бота

```bash
python bot.py
```

## 📱 Команды в Telegram

- `/start` — Запуск и приветствие с кнопками быстрого расписания.
- `/schedule` — Интерактивное меню расписания по дням недели.
- `/check` — Принудительная ручная проверка жалоб на Majestic RP прямо сейчас.
- `/memory` — Посмотреть всё, что агент помнит о вас в постоянной базе.
- `/clear` — Очистить текущий контекст диалога.
- `/help` — Подсказка по командам.
